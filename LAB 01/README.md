## Description

### Linear Search

Linear Search checks each element sequentially until the required element is found or the entire array is searched.

**Time Complexity:** `O(n)`

**Space Complexity:** `O(1)`

### Binary Search

Binary Search searches a sorted array by repeatedly dividing the search interval into two halves.

**Time Complexity:** `O(log n)`

**Space Complexity:** `O(1)`
